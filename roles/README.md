# 角色資料夾

一個角色一個資料夾，`ROLE.md` 定義該角色的職責與界線。
在同一個資料夾開對話，就是同一位角色；只管自己那一塊。

| 資料夾 | 角色 | 可改 | 不可改 |
|---|---|---|---|
| `coordinator/` | Claude 總協調 | `index.html`、合併、驗收 | 已核對的詳解內容 |
| `tools/` | 工具腳本 | `tools/` | `index.html`、題庫內容 |
| `question-bank/` | 題庫草稿（Grok/ChatGPT/Muse） | 自己分支的 `drafts/` | `index.html`、既有 Case |

通用規則見根目錄 `AGENTS.md`。
